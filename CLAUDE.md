# Project Instructions

## Team progress log

`FOR_THE_TEAM.md` (repo root) is a casual, plain-language changelog read by non-engineer teammates.

**Whenever the user signals that a major feature is finished** — e.g. "done with X", "that feature's complete", "wrapped up X", "ship-ready" — update `FOR_THE_TEAM.md` as part of that turn by invoking the `/update-team` skill, which carries the full append format and rules.

Only do this for *major* features the user calls done — not small tweaks or every turn. If unsure whether something qualifies, ask.
